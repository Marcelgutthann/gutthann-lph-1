# LPH 1 - Grundlagenermittlung - Checkliste

Diese Checkliste deckt die Grundleistungen nach HOAI Paragraph 33 Anlage 10.1 ab.

## 1.1 Klären der Aufgabenstellung

- [ ] Aufgabenstellung des Auftraggebers vorliegen (z.B. Aufgabenbeschreibung, Bauherrenwunsch, Bedarfsplan)
- [ ] Projektziele dokumentiert (Funktion, Qualität, Termin, Kosten, Nachhaltigkeit)
- [ ] Erfordernis Bedarfsplanung geklaert
- [ ] Erfordernis Standortanalyse geklaert
- [ ] Zielkonflikte identifiziert und mit AG abgestimmt
- [ ] Vertragsstand dokumentiert (Architektenvertrag Stufe 1: LPH 1+2)

## 1.2 Beratung zum gesamten Leistungs- und Untersuchungsbedarf

- [ ] Fachplaner-Bedarf identifiziert (Tragwerk, TGA, Brandschutz, Bauphysik, Vermessung, Bodengutachten, Schadstoffe, SiGeKo, Vergabe)
- [ ] Genehmigungsbedarf grob abgeschaetzt (Bauantrag, vereinfachtes Verfahren, verfahrensfrei)
- [ ] Empfehlungen zur Vergabe der Fachplanerleistungen formuliert
- [ ] Zeitplan fuer Vorab-Untersuchungen erstellt
- [ ] Sondergutachten (Verkehr, Akustik, Schall, etc.) gepruft

## 1.3 Formulieren von Entscheidungshilfen fuer Standortwahl

- [ ] B-Plan / Flaechennutzungsplan beschafft
- [ ] Grundbuchauszug / Liegenschaftskarte beschafft
- [ ] Erschliessungsmoeglichkeiten geprueft (Wasser, Abwasser, Strom, Telekommunikation)
- [ ] Altlasten / Schadstoffe in Standort gepruft (Altlastenkataster)
- [ ] Topografie / Hoehenlinien / Geotechnik gepruft
- [ ] Naturschutz / Landschaftsschutz / Denkmalschutz gepruft
- [ ] Lagebeurteilung dokumentiert

## 1.4 Zusammenfassen der Ergebnisse

- [ ] Grundlagenermittlungsbericht erstellt (HTML / PDF)
- [ ] Alle Pflicht-Kapitel ausgearbeitet (1.1 bis 1.4 + Zusammenfassung)
- [ ] Quellen-Belege pro Aussage dokumentiert
- [ ] Beteiligtenliste (Stand der Akquise) erstellt
- [ ] Kostenrahmen grob abgeschaetzt (Optional, Vorbereitung LPH 2)
- [ ] Grobterminplan grob skizziert (Optional, Vorbereitung LPH 2)
- [ ] Bericht zur Freigabe an AG vorgelegt

## Zentrale Pflicht-Dateien im Projekt

| Datei | Zweck |
|---|---|
| Aufgabenbeschreibung AG (PDF) | Was will der Bauherr - Grundlage aller Planung |
| Beteiligtenliste (XLSX/PDF) | Wer ist beteiligt (Stand Akquise) |
| Standort-Unterlagen | B-Plan, FNP, Flurkarte, Grundbuch |
| Bestandsunterlagen (falls vorhanden) | Plaene, Statik, TGA |
| Konzeptskizzen / Beilagen | Erste Ideen, Skizzen, Praesentationen |
| Korrespondenz | E-Mails, Aktennotizen, Gespraechsnotizen |
| Vertragsunterlagen | Architektenvertrag Stufe 1 |

## Pre-Flight Check vor Freigabe

- [ ] Keine projektspezifischen Daten vergessen (Schreibfehler, falsche Namen)?
- [ ] Alle Beteiligten korrekt mit Funktion / Kontakt?
- [ ] Aufgabenbeschreibung vollstaendig verstanden und reflektiert?
- [ ] Empfehlung Fachplaner-Beauftragungen klar und prioritisiert?
- [ ] Zielkonflikte mit AG abgestimmt und schriftlich dokumentiert?
- [ ] Stand-Datum auf Titelseite aktuell?
